5 Trees & BST

Tree ek hierarchical structure hai: ek root, aur har node ke children. Binary tree mein har node ke maximum 2 children hote hain (left aur right). Interviews mein sabse zyada puche jaane wale topics mein se ek.

Core idea
BST (Binary Search Tree) mein har node ke liye: left subtree ki saari values chhoti, right subtree ki saari values badi. Isliye BST ka inorder traversal sorted hota hai, aur search/insert/delete O(h) mein hote hain (h = height).
Main patterns

1. Traversals: Inorder (Left, Node, Right), Preorder (Node, Left, Right), Postorder (Left, Right, Node), aur Level Order (BFS, queue se).

2. Height wali recursion: height(node) = 1 + max(height(left), height(right)). Diameter, balanced tree, max path sum jaise problems isi pe bante hain.

3. Global answer: jab answer kisi bhi node pe ban sakta ho (diameter, max path sum), to ek global variable rakho aur recursion se child ka result return karo.

4. LCA (Lowest Common Ancestor): agar p aur q alag-alag sides mein mile, to current node hi LCA hai. BST mein value compare karke ek hi side jao.

int height(TreeNode root) { if (root == null) return 0; // base case return 1 + Math.max(height(root.left), height(root.right)); } TreeNode lca(TreeNode root, TreeNode p, TreeNode q) { if (root == null || root == p || root == q) return root; TreeNode l = lca(root.left, p, q); TreeNode r = lca(root.right, p, q); if (l != null && r != null) return root; // dono side mile return l != null ? l : r; }
💡 Yaad rakhoHar tree problem ko ek sawal mein todo: ek node pe kya karna hai aur left/right se kya result aayega. Baaki recursion sambhal leti hai.

6 Searching & Sorting

Sorting khud ek topic hai aur bahut saare problems ko aasaan banata hai: data sort kar do to two pointers, binary search ya greedy lag jaata hai.

Core idea
Linear search O(n) kisi bhi array pe chalta hai. Sorted array pe binary search O(log n). Sorting ka best general cost O(n log n) hai.
Main patterns

Algorithms: Bubble, Selection, Insertion = O(n²). Merge Sort = O(n log n), stable, O(n) extra space. Quick Sort = average O(n log n), worst O(n²). Heap Sort = O(n log n), in-place. Counting Sort = O(n + k) jab range chhoti ho.

Java mein: Arrays.sort() primitives ke liye dual-pivot quicksort, objects ke liye TimSort (stable) use karta hai.

Patterns: sort + two pointers, custom comparator (intervals), Dutch National Flag (0,1,2 sort), merge two sorted arrays, quickselect (kth element O(n) average).

int[][] intervals = ...; Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0])); // start time se sort // Dutch National Flag: 0, 1, 2 ko ek pass mein sort karo int lo = 0, mid = 0, hi = a.length - 1; while (mid <= hi) { if (a[mid] == 0) swap(a, lo++, mid++); else if (a[mid] == 1) mid++; else swap(a, mid, hi--); }
⚠️ Comparator mein dhyana[0] - b[0] likhne se integer overflow ho sakta hai. Hamesha Integer.compare(a[0], b[0]) use karo.

7 Binary Search

Binary search sirf sorted array tak limited nahi hai. Jahan bhi answer ka koi monotonic pattern ho (ek point ke baad hamesha true), wahan chal jaata hai.

Core idea
Search space ko har step mein aadha karo. Time O(log n). Binary search on answer: jab sawal hai "minimum X jisme kaam ho jaaye", to X ki range pe binary search karo aur ek check(x) function likho.
Main patterns

1. Classic: sorted array mein target dhundo. 2. Bounds: first/last occurrence, lower/upper bound. 3. Rotated sorted array: dekho kaunsa half sorted hai. 4. On answer: Koko eating bananas, ship capacity, split array.

int lo = 0, hi = n - 1, ans = -1; while (lo <= hi) { int mid = lo + (hi - lo) / 2; // overflow safe if (check(mid)) { ans = mid; hi = mid - 1; } // pehla true dhundo else lo = mid + 1; } return ans;
⚠️ Off-by-oneInfinite loop tab hota hai jab lo ya hi update nahi hota. Hamesha decide karo: loop lo <= hi hai ya lo < hi, aur usi hisaab se mid ±1 karo.

8 Heaps & Priority Queue

Heap ek complete binary tree hai jisme parent hamesha child se chhota (min-heap) ya bada (max-heap) hota hai. Java mein iska use PriorityQueue se hota hai.

Core idea
Top element O(1) mein milta hai, insert aur remove O(log n) mein. Bahut saari problems mein "sabse chhota/bada K" nikalna hota hai, wahan heap perfect hai.
Main patterns

1. Top K: K largest chahiye to min-heap of size K rakho. 2. K-way merge: K sorted lists ke heads heap mein rakho. 3. Two heaps: median ke liye ek max-heap (left half) aur ek min-heap (right half). 4. Scheduling: task scheduler, meeting rooms II.

PriorityQueue<Integer> pq = new PriorityQueue<>(); // min-heap for (int x : nums) { pq.add(x); if (pq.size() > k) pq.poll(); // sabse chhota nikaal do } return pq.peek(); // kth largest PriorityQueue<Integer> max = new PriorityQueue<>(Collections.reverseOrder());
💡 Yaad rakhoK largest chahiye to min-heap use karo, K smallest chahiye to max-heap. Ulta lagta hai par isi se heap size K pe rehta hai.

9 Graphs

Graph = nodes (vertices) aur unke beech edges. Social network, maps, course dependencies, grid problems, sab graph hain.

Core idea
Graph ko adjacency list mein store karo (List<List<Integer>>). Har traversal mein visited track karna zaroori hai, nahi to infinite loop.
Main patterns

BFS (queue): level-by-level, unweighted graph mein shortest path. DFS (recursion/stack): connected components, cycle detection, path dhundna.

Topological Sort (DAG): Kahn's algorithm, indegree se. Course Schedule jaise problems.

Dijkstra: weighted graph (non-negative) mein shortest path, PriorityQueue se, O((V+E) log V). Union-Find: components aur cycle.

Grid problems: har cell ek node, 4 directions uske neighbours. Number of Islands, Rotting Oranges.

boolean[] vis = new boolean[n]; Queue<Integer> q = new LinkedList<>(); q.add(start); vis[start] = true; // push karte time hi mark karo while (!q.isEmpty()) { int u = q.poll(); for (int v : adj.get(u)) { if (!vis[v]) { vis[v] = true; q.add(v); } } }
⚠️ BFS mein visitedVisited ko queue mein daalte waqt mark karo, nikalte waqt nahi. Warna ek node queue mein kai baar aa jaayega.

10 Greedy Algorithms

Greedy mein har step pe wahi choose karte hain jo us waqt sabse achha lag raha ho, is umeed se ki end mein bhi best answer milega.

Core idea
Greedy tab chalta hai jab local best choice se global best banta ho. Aksar pehle data sort karna padta hai.
Main patterns

Patterns: Interval scheduling (end time se sort), Jump Game (farthest reach track karo), Gas Station, Candy distribution, Minimum Platforms, Fractional Knapsack.

Proof ka tareeka: ek chhota counter-example sochkar check karo. Agar greedy fail ho jaaye, to shayad DP chahiye (jaise arbitrary coins ka Coin Change).

Arrays.sort(iv, (a, b) -> Integer.compare(a[1], b[1])); // end time se sort int count = 0, end = Integer.MIN_VALUE; for (int[] x : iv) { if (x[0] >= end) { count++; end = x[1]; } // overlap nahi hai to le lo } return count; // maximum non-overlapping intervals
💡 Yaad rakhoSort ka key sahi chuno: intervals mein end time, jobs mein deadline/profit. Galat key se greedy galat answer deta hai.

11 Dynamic Programming

DP = ek badi problem ko chhote subproblems mein todna, aur har subproblem ka answer ek baar solve karke store kar lena, taaki baar-baar compute na ho.

Core idea
DP tab lagta hai jab: (1) overlapping subproblems hon, aur (2) optimal substructure ho. Steps: state define karo, transition likho, base case, order, aur final answer kahan hai.
Main patterns

Memoization (top-down): recursion + cache. Tabulation (bottom-up): table bharte jao.

Common patterns: 1D (Climbing Stairs, House Robber), 2D grid (Unique Paths), 0/1 Knapsack (take / not take), Subset Sum, Coin Change, LIS, LCS, Edit Distance.

Sochne ka tareeka: pehle plain recursion likho, phir dekho kaunse parameters change hote hain (wahi state hai), phir cache lagao, aur last mein table banao.

// House Robber: dp[i] = max(dp[i-1], dp[i-2] + nums[i]) int prev2 = 0, prev1 = 0; for (int x : nums) { int cur = Math.max(prev1, prev2 + x); prev2 = prev1; prev1 = cur; } return prev1; // Coin Change (min coins) int[] dp = new int[amt + 1]; Arrays.fill(dp, amt + 1); dp[0] = 0; for (int a = 1; a <= amt; a++) for (int c : coins) if (c <= a) dp[a] = Math.min(dp[a], dp[a - c] + 1); return dp[amt] > amt ? -1 : dp[amt];
💡 Key insightAgar dp[i] sirf pichle 1-2 values pe depend karta hai, to poori table ki jagah 2 variables se kaam chal jaata hai (space O(1)).

12 Tries & Advanced Trees

Trie (prefix tree) strings ko character-by-character store karta hai. Autocomplete, spell checker aur "is prefix se kitne words" jaise sawalon mein kaam aata hai.

Core idea
Har node mein 26 children (a–z) aur ek isEnd flag. Insert/search/startsWith teeno O(L) mein, L = word ki length.
Main patterns

Use cases: prefix search, Word Search II, longest common prefix, replace words.

Advanced trees (overview): Segment Tree range query/update O(log n). Fenwick Tree (BIT) prefix sum with updates. AVL / Red-Black self-balancing BST, height hamesha O(log n) (Java ka TreeMap Red-Black hai).

class TrieNode { TrieNode[] ch = new TrieNode[26]; boolean end; } void insert(String w) { TrieNode cur = root; for (char c : w.toCharArray()) { if (cur.ch[c - 'a'] == null) cur.ch[c - 'a'] = new TrieNode(); cur = cur.ch[c - 'a']; } cur.end = true; }
💡 Yaad rakhoHashSet mein prefix search ke liye har word check karna padta hai. Trie mein prefix ke saath hi seedha ruk jaate ho, isliye wo prefix problems mein jeetta hai.

13 Bit Manipulation

Computer sab kuch bits mein store karta hai. Bit tricks se kai problems O(1) space aur bahut fast mein ho jaate hain.

Core idea
Operators: & (AND), | (OR), ^ (XOR), ~ (NOT), << aur >> (shift). XOR ki khaas baat: a ^ a = 0 aur a ^ 0 = a.
Main patterns

Common tricks: i-th bit check (n >> i) & 1, set n | (1 << i), clear n & ~(1 << i), toggle n ^ (1 << i).

n & (n-1) sabse right wala set bit hata deta hai. Power of 2 check: n > 0 && (n & (n-1)) == 0.

XOR pattern: array mein sab do-do baar hain sirf ek ek baar, to sabko XOR kar do. Subsets: 0 se 2ⁿ−1 tak ke masks.

int count = 0; // set bits count (Brian Kernighan) while (n != 0) { n &= (n - 1); count++; } int single = 0; // Single Number for (int x : nums) single ^= x; for (int mask = 0; mask < (1 << n); mask++) { // saare subsets for (int i = 0; i < n; i++) if ((mask & (1 << i)) != 0) { /* nums[i] subset mein hai */ } }
⚠️ PrecedenceBit operators ki precedence == se kam hoti hai. Hamesha brackets lagao: (n & 1) == 1.

🔢 Topic 14 of 14
14 Math & Number Theory

Coding rounds mein kuch math concepts baar-baar aate hain: GCD, primes, power aur modulo. Ye chhote hain par seekhna zaroori hai.

Core idea
GCD Euclid se O(log n): gcd(a, b) = gcd(b, a % b). LCM = a / gcd × b (pehle divide karo, overflow se bachne ke liye). Prime check sirf √n tak. Sieve of Eratosthenes se 1 se n tak ke saare primes O(n log log n) mein.
Main patterns

Modular arithmetic: bade answers 10^9 + 7 se mod karke maangte hain. (a + b) % m aur (a × b) % m formula use karo, aur multiply se pehle long mein convert karo.

Fast power: x^n ko O(log n) mein, n ko aadha karte hue.

Aur tricks: digits nikalna (% 10, / 10), factorial ke trailing zeroes (n/5 + n/25 + ...), integer overflow ka dhyan.

int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); } boolean[] comp = new boolean[n + 1]; // Sieve for (int i = 2; (long) i * i <= n; i++) if (!comp[i]) for (int j = i * i; j <= n; j += i) comp[j] = true; long power(long x, long n, long mod) { // fast power long res = 1; x %= mod; while (n > 0) { if ((n & 1) == 1) res = res * x % mod; x = x * x % mod; n >>= 1; } return res; }
💡 Yaad rakhoJab bhi answer bahut bada ho sakta hai, pehle sochlo long chahiye ya mod. Int overflow chupke se galat answer deta hai.

Try karo: Count Primes, Pow(x, n), Factorial Trailing Zeroes, Palindrome Number, Sqrt(x)
